# 数值分析

[返回仓库总览](../README.md)

通过自己实现数值算法，理解计算方法的原理、误差、稳定性与适用条件。

## 语言与组织

同时使用 **C、C++ 和 Python**：C/C++ 用于算法与计算过程的实现，Python 用于算法原型、误差分析和绘图；具体任务可任选或进行跨语言对照。

每个作业或专题建立独立目录，按需包含 `c/`、`cpp/`、`python/` 和 `tests/`，并记录实际编译、运行命令与依赖。

## 内容与验证

可能涉及方程求根、插值与逼近、数值微积分、线性方程组及常微分方程数值解；实际顺序以课程为准。

- 与解析解、已知结果或可信库函数对照，说明参考值来源。
- 检查绝对误差、相对误差、停止条件和异常输入；参考值为零时避免直接除零。
- 对适用算法改变步长、网格或迭代次数，检查收敛趋势。
- 区分舍入误差、离散误差与问题本身的病态性，不只报告运行时间。

核心方法由本人实现，现成求解器作为对照时明确标注。当前尚未录入具体任务。
