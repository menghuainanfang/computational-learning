# 梯度下降法实现与验证

本专题将可复用方法放在 `模块/`，将具体问题及其完整运行流程放在 `实例/`。
阅读入口是 `实例/一维函数.py`，数学循环位于 `模块/梯度下降.py`。

仓库：[computational-learning](https://github.com/menghuainanfang/computational-learning)。
目录：`最优化/梯度下降法`。版本：0.3.0。许可：MIT。

## 模块职责

| 文件 | 输入 | 输出 |
| --- | --- | --- |
| 自动微分.py | 目标函数 f | 梯度函数 grad_f |
| 步长策略.py | f、当前点、下降方向与配置 | 所选策略的步长 |
| 回溯搜索.py | f、当前点、梯度、方向与回溯配置 | 满足 Armijo 的步长 |
| 扩张中点搜索.py | f、梯度、方向与扩张配置 | 扩张或单次中点步长 |
| 次梯度下降.py | f、初始点、用户提供的次梯度 | 指定次数的迭代历史 |
| 梯度下降.py | f、初始点、梯度及停止条件 | 优化结果 |
| 结果记录.py | 参数、函数值、梯度长度和步长记录 | 结果与历史容器 |
| 绘图.py | 优化结果，轨迹图还需要 f | 曲线或轨迹图 |

实例先定义自己的目标函数，然后调用 `make_gradient`、`gradient_descent`
和绘图函数。求解器每轮向步长模块请求步长，不依赖具体例题或绘图。

参数统一为一维实数数组；目标函数返回一个实数，梯度与参数形状相同。
结果包含初始点与最终点，五种历史数组均有 `nit + 1` 条记录。
`success=True` 表示达到梯度容差。无效配置与接口错误抛出异常，数值失败
则在结果中说明停止原因。

## 验证结果

自动测试 **70 项通过**，用时 2.89 秒。测试覆盖一维和多维二次函数、
原型中的四次函数、解析梯度与差分梯度、五种步长、数值失败、停止条件、
记录维数与绘图。回溯测试核对充分下降，扩张测试核对只试一次中点、
中点接受与拒绝、回溯后继续扩张，以及达到上界时停止。
函数计数与实际受计数的调用对照；次梯度测试核对零点和振荡的完整 20 次更新。
六个实例均在非交互绘图环境中运行成功，新生成的两组图片已进行视觉检查。

可编辑安装、源码分发包和 wheel 构建均成功。独立环境安装 wheel 后，
从专题目录之外导入模块，完成两种线搜索与次梯度迭代；核心模块不依赖 Matplotlib。

| 实例 | 结果 |
| --- | --- |
| 一维函数 | w=-1.2347728，f(w)=-0.169969284，43 次更新达到梯度容差 |
| 二维函数 | 数值结果接近解析解 [0, 1] |
| 二次型 | 五维解与解析解的距离为 9.046e-9 |
| 步长比较 | 固定步长 1、固定步长 0.1 和有界搜索达到容差；递减策略达到迭代上限 |
| 绝对值函数 | 初始点 2.0 的固定步长第 4 次到零；初始点 2.1 的固定步长在 0.1 与 -0.4 间振荡 |
| 线搜索比较 | 两种策略均完成 60 次更新，仍未达到梯度容差 |

线搜索实例使用 f(w)=0.5*(w[0]²+10*w[1]²)、w₀=[4,3]、初始步长 0.03，
最大更新次数 60、梯度容差 1e-7。结果如下：

| 策略 | 更新次数 | 最终函数值 | 函数调用 | 梯度调用 | 停止原因 |
| --- | --- | --- | --- | --- | --- |
| Armijo 回溯 | 60 | 0.2068702784 | 303 | 61 | 达到更新上限 |
| 扩张＋单次中点 | 60 | 9.004734609e-12 | 561 | 61 | 达到更新上限 |

这个例子中，扩张中点用更多试探换得较小函数值。函数调用量包含求解器内部
的目标函数检查、自动微分和搜索试探，不能直接作为运行时间。

## 限制与后续方向

梯度小表示接近驻点，不保证全局最优。固定和递减步长依赖问题的尺度，
有界数值搜索在非凸函数上不保证找到区间内的全局最佳步长。
当前一维例题采用递减步长时，1000 次更新后得到 w=-0.39532823、
f(w)=-0.075451461，仍未达到梯度容差。

目标函数需兼容 Autograd，或者由用户提供梯度。约束问题与复数参数暂不支持。
一维、二维支持轨迹图，高维支持收敛曲线。保存全部历史的内存开销随维数和
迭代次数增长。声明支持 Python 3.10 及以上，本地只验证了 Python 3.13.2。

次梯度迭代由用户明确给出次梯度，按指定次数返回历史。Armijo 的可微性条件
不能直接用于绝对值的零点。扩张中点策略是启发式规则，不保证线上全局最优。
传入外部构造的梯度时，其中直接调用目标函数的次数不包含在求解器计数中。

后续可以研究上一轮步长的复用，以及相同函数求值预算下的策略比较。
搜索公式、单次中点演示和次梯度说明见 [线搜索与次梯度](线搜索与次梯度.md)。
