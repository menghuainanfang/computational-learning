# 线搜索与次梯度

## Armijo 回溯

当前点为 w，梯度为 g，方向 d 满足 gᵀd < 0。
给定初始步长 alpha，检查：

$$f(w+\alpha d) \le f(w) + c\alpha g^T d,\qquad 0<c<1.$$

右侧要求下降量与方向导数相联系。若不满足条件，就将步长乘以
`shrink`（默认 0.5），直到找到第一个满足条件的步长。对可微函数的
严格下降方向，足够小的步长满足这一条件；实现使用有限的回溯次数。
非有限试探值视为不满足条件，继续回溯。

## 扩张＋单次中点

这个策略包含三个阶段：

1. 初始步长不满足 Armijo 时，先回溯到满足条件的步长。
2. 将成功步长乘以 `growth`，并限制在 `alpha_max` 内。只有同时满足
   Armijo 条件、且函数值比上次成功试探更低时，才接受扩张。
3. 第一次扩张失败后，试一次成功步长和失败步长的算术中点。
   中点也必须同时满足上述两项条件，随后返回。

若扩张没有失败，而是达到步长上界或次数上限，则直接返回成功步长。
`max_backtracks` 限制缩小次数，`max_expansions` 限制扩张次数。

例如 f(w)=w²，w=2，g=4，d=-4，从 alpha=0.18 开始：

| 试探步长 | 函数值 (2-4*alpha)² | 处理 |
| --- | --- | --- |
| 0.18 | 1.6384 | 接受初始步长 |
| 0.36 | 0.3136 | 接受扩张 |
| 0.72 | 0.7744 | 比上次高，停止扩张 |
| 0.54 | 0.0256 | 接受单次中点 |

返回 0.54。该直线的精确最小步长是 0.5；这个策略按自己的接受规则停止，
不继续细化中点。每次试探需要一次函数求值，实例也比较累计函数调用量。

## 绝对值的次梯度

f(w)=|w| 在 w=0 不可微，零点次微分是 [-1,1]。
实例明确选择零作为零点次梯度，其他点选择 sign(w)：

$$w_{k+1}=w_k-\alpha_k\operatorname{sign}(w_k).$$

从 w₀=2、固定步长 0.5 出发，第四步恰好到零，随后保持为零。
从 w₀=2.1 出发，相同固定步长会在 0.1 与 -0.4 之间振荡。
递减步长 1/(k+1) 用于比较振荡幅度随步长缩小的变化。
为保留完整实验，两种策略都完成 20 次更新，历史包含 21 个点。

## 适用范围

Armijo 的上述保证使用可微性和严格下降方向。不能将零点的选定次梯度
当成绝对值的普通导数来引用这项保证。扩张中点策略是启发式步长规则，
不保证找到线上全局最小点，也不声称比回溯在所有问题上更快。
函数调用量是求值工作量的指标，运行时间还取决于各次求值和求导的成本。
