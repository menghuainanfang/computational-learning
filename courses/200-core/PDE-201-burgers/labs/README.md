# 非线性有限元与时间实验

[非线性有限元.py](非线性有限元.py)提供空间求积、C/B/G装配、五种时间求解入口；[运行时间实验.py](运行时间实验.py)固定半离散系统比较时间阶，并比较三种黏性。

运行：从课程根目录执行 `python labs/运行时间实验.py`。精简数据见[时间与黏性结果](results/时间与黏性结果.json)、[时间误差CSV](results/时间误差.csv)。图保存在notes/figures，不保存NPZ。

[第四篇](../notes/04-误差与计算证据.md)末尾给出两项自主讨论：比较front与Newton的方程、两列残差及成本信息；从非线性积分推导Jacobian并定位代码。可先完成其中一项，把推导、程序位置和数据解释写在同一份记录中。若继续改变实验条件，需保留物理步数与非线性子求解次数，以便比较。
