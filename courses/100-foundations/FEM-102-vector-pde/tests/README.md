# 验证内容与判据

[labs/双分量耦合实验.py](../labs/双分量耦合实验.py)统一完成计算与验证，避免重复维护装配代码。

- 用独立Kronecker构造对照FEALPy四块装配，最大差4.44e-16。
- 同时置换向量与矩阵行列，矩阵作用差为0。
- 去除非对角反应系数后跨分量块为0。
- 检查全部分量的非零边界以及原系统内部残差，阈值分别1e-12与1e-10。
- 光滑制造解最后一级整体L²观测阶要求1.9—2.1，H¹半范数要求0.95—1.05。本次分别1.99866与0.99934。

这些判据针对当前模型；纯Neumann、交叉扩散、高阶元和强对流问题需各自的理论与验证。数据见[结果目录](../labs/results/收敛结果.csv)。

误差推导与结果解释见[求解实现与误差验证](../notes/03-求解实现与误差验证.md)，块编号与整体边界消元见[乘积空间与块装配](../notes/02-乘积空间与块装配.md)。
