# 双分量耦合实验

按[耦合模型](../notes/01-耦合模型与向量弱问题.md)、[块装配](../notes/02-乘积空间与块装配.md)理解程序，并结合[误差理论与验证](../notes/03-求解实现与误差验证.md)阅读结果。从课程根目录运行 `python labs/双分量耦合实验.py`。

程序固定非对称反应矩阵C=[[2,-1],[-0.5,2]]、速度(1,2)、扩散1与边界(1,2)，对制造解逐级加密。结果位于[收敛表](results/收敛结果.csv)和[结构核对](results/结构核对.json)，三幅图由程序再生成，不保存完整场数组。
