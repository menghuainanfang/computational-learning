# 数值验证

验证由[labs/稳态输运实验.py](../labs/稳态输运实验.py)统一执行，避免维护重复求解代码。从课程目录运行 `python labs/稳态输运实验.py`。

- 几何：独立计算雅可比逆变换后的梯度，与FEALPy基函数梯度对照。
- 对流：常系数P1单元解析积分与积分器对照，检查试探、测试侧方向。
- 装配：按局部到全局映射手动COO累加，与BilinearForm结果比较。
- 边界与求解：边界误差小于1e-12，原矩阵内部行的归一化残差小于1e-10。
- 收敛：四档网格，末级L²观测阶在1.9—2.1，H¹半范数观测阶在0.95—1.05。该判据用于当前光滑制造解，不是任意模型的通用要求。

实际末级阶为1.9986和0.9993，边界误差为0，内部残差最大约6.58e-14。具体数值见[收敛结果](../labs/results/收敛结果.csv)与[装配核对](../labs/results/装配核对.json)。理论条件与误差推导见[正文](../notes/01-稳态输运问题的有限元方法.md)。
