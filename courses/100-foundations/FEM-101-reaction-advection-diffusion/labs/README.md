# 稳态输运实验

阅读[模型](../notes/01-稳态输运模型与弱问题.md)、[离散实现](../notes/02-三角形有限元与全局装配.md)和[误差验证](../notes/03-有限元误差与收敛验证.md)后，运行[稳态输运实验.py](稳态输运实验.py)。模型为单位正方形上的 $a=c=1$、$\boldsymbol{\beta}=(1,2)^T$，制造解为 1+sin(πx)sin(πy)，全边界值为1。

实验固定模型、空间次数与求解方法，只改变n=8、16、32、64，比较积分误差及观测阶。输出[收敛数据](results/收敛结果.csv)和[装配核对](results/装配核对.json)，插图保存在notes/figures。
