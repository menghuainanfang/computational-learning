## 语言与组织

同时使用 **C、C++ 和 Python**：Python 用于算法原型、数据处理和可视化，C/C++ 可用于重现核心计算及比较实现。按学习目标选择，不预设必须使用某个框架。

每个作业或专题建立独立目录，按需包含 `c/`、`cpp/`、`python/` 和 `tests/`，记录运行命令、依赖与数据获取方式。

## 内容与验证

可能涉及回归、分类、聚类、优化和神经网络基础；实际顺序以课程为准。

- 先用小型已知数据检查形状、损失与预测结果；涉及梯度时按需进行数值梯度核对。
- 明确训练集、验证集和测试集，预处理参数只从训练数据拟合，避免数据泄漏。
- 记录数据来源、划分方式、随机种子、超参数、评价指标和工具版本。
- 与简单基准或第三方实现对照，解释差异；不只展示训练集分数。

核心学习算法由本人实现。第三方模型用于基准时注明用途；大型数据与模型产物不直接入库，必要的小型测试数据可保留。当前尚未录入具体任务。
