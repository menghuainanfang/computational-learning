# 数据结构与算法

[返回仓库总览](../README.md)

通过自己实现数据结构与算法，理解正确性、操作代价和不同表示方式之间的取舍。

## 语言与组织

同时使用 **C、C++ 和 Python**：C 关注指针和内存管理，C++ 关注类型与抽象，Python 便于表达思路和构造对照实验。按题目选择语言，需要时比较多种实现。

每个作业或专题建立独立目录，按需包含 `c/`、`cpp/`、`python/` 和 `tests/`，记录工具版本、编译和运行命令。

## 内容与验证

可能涉及线性表、栈与队列、树、图、查找、排序及常见算法设计方法；实际顺序以课程为准。

- 检查正常输入、空输入、单元素、边界规模和题目允许的重复元素。
- 对结构操作检查不变量，如元素数量、连接关系和有序性。
- 说明时间与空间复杂度，并区分理论分析与实测性能。
- C/C++ 实现关注越界、资源释放、对象生命周期和无效指针；按工具可用性使用相应检查。

实现目标若是某个数据结构本身，不以现成容器替代核心练习；标准库用于辅助或对照时说明范围。当前尚未录入具体任务。
